# CanvasXpress example notebooks

One Jupyter notebook per gallery example at https://www.canvasxpress.org/examples.html, generated by the CanvasXpress site build, in Python (`notebooks/`) and R (`notebooks/r/`). Open any notebook on Binder from the example's **Jupyter Code** or **R Code** tab, or launch the whole collection:

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/neuhausi/canvasxpress-notebooks/main?labpath=notebooks)

The Python notebooks need only the `canvasxpress` package (`pip install "canvasxpress[jupyter]"`, see `requirements.txt`); the R notebooks need the `canvasXpress` CRAN package (`install.packages("canvasXpress")`, see `install.R`).
