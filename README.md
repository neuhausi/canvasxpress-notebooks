# CanvasXpress example notebooks

One Jupyter notebook per gallery example at https://www.canvasxpress.org/examples.html, generated by the CanvasXpress site build. Open any notebook on Binder from the example's **Jupyter Code** tab, or launch the whole collection:

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/neuhausi/canvasxpress-notebooks/main?labpath=notebooks)

Each notebook needs only the `canvasxpress` Python package (`pip install "canvasxpress[jupyter]"`, see `requirements.txt`).
